# EnerLuma Capstone Presentation Prompt

Create a 12-slide PowerPoint presentation for a final-year B.Tech CSE capstone project titled:

**EnerLuma – Smart Home Energy & Water Consumption Dashboard**

Team: **Divyanshu Singh, Shivam Prakash, Aditya Verma**
Institute: **Lovely Professional University**
Mentor: **Cherry Khosla**
Course: **CSE439 (2024–25)**

The deck must feel like a professional startup investor pitch, not a college template. It should look designed by a top-tier brand studio: precise spacing, editorial composition, strong hierarchy, real negative space, and restrained but premium motion cues. Avoid generic corporate layouts, overused gradients, and stock-photo visuals.

## Core Visual Identity

Use a strict dark theme throughout.

- Base background: near-black `#0A0E1A`
- Card surfaces: dark navy `#0D1B2E`
- Secondary panels: slightly lighter navy `#12233A`
- Primary accent: electric cyan `#00D4FF`
- Secondary accent: deep violet `#7B2FBE`
- Critical stats / alerts: warm amber `#FF9500`
- Success / positive metrics: muted mint or teal, used sparingly
- Text: off-white `#F5F7FB` and cool gray `#A9B4C4`

Use subtle textures, circuit-like patterns, thin data-stream lines, low-opacity grid noise, and soft ambient glows. The background should feel high-tech and intentional, never flat.

## Typography

Use premium modern fonts only.

- Headlines: Plus Jakarta Sans Bold or Clash Display
- Body: Inter Regular
- Section titles: 28–32 pt
- Hero titles: 52–60 pt
- Body copy: 13–15 pt
- All-caps labels: add generous letter-spacing of `+0.12em`
- Never use default PowerPoint fonts
- Never use gradient text

## Layout Rules

Every slide must use a different layout structure. No repeated grid pattern.

- Use asymmetric compositions
- Mix full-bleed image or texture panels with text blocks
- Use diagonal divisions on some slides
- Use overlapping cards and large number callouts
- Use editorial framing, not standard business slides
- One glowing highlight element per slide only
- Card borders should be 1px and slightly lighter than the surface color, never harsh
- Icons must be monoline SVG style, consistent stroke weight, using Lucide or Phosphor style icons only
- Data visualizations should use thin lines, muted gridlines, and one highlighted datapoint
- Keep every slide spacious and uncluttered

## Deck Tone

The presentation should communicate:

- EnerLuma is a real product, not a classroom demo
- Smart home utility tracking can be intuitive and measurable
- AI insight and dashboarding create clear user value
- The project is technically credible, polished, and ready for future expansion

## Slide-by-Slide Content

### Slide 1: Cover
- Large project title: **EnerLuma**
- Subtitle: **MERN Stack · LPU · CSE439 2024–25**
- Minimal team row at bottom with names
- Background: abstract dark circuit / data-stream texture, no stock photos
- Layout: full-bleed texture with a bold left-aligned title block and subtle cyan/violet ambient glow
- Add a faint oversized `01` or project code treatment behind the title

### Slide 2: Problem Statement
- 4 problem areas in a 2×2 asymmetric card grid
- Each card contains:
  - One monoline icon
  - A bold one-line problem title
  - A single supporting stat
- No paragraphs
- Suggested problem angles:
  - Utility bills are unclear
  - Water and energy waste go unnoticed
  - Manual tracking is inconsistent
  - Alerts arrive too late
- Highlight one metric in amber

### Slide 3: Objectives
- Numbered list layout from `01` to `06`
- Large faded numbers behind each objective title
- Clean scannable structure with plenty of whitespace
- Objectives should include:
  - Monitor energy consumption in real time
  - Track water usage and anomalies
  - Visualize trends and peak loads
  - Trigger intelligent alerts
  - Surface AI-based recommendations
  - Support MERN-based responsive web access

### Slide 4: Existing vs Proposed
- Side-by-side split layout
- Left column: muted, desaturated, labeled as existing/manual approach
- Right column: energetic, full-color EnerLuma solution
- Include 6 comparison rows
- Rows may compare:
  - Data capture
  - Visibility
  - Alerts
  - Trend analysis
  - Recommendation quality
  - User experience
- Use cyan to emphasize the proposed side

### Slide 5: Tech Stack
- Hexagonal or circular node-cluster layout
- Show MERN stack plus supporting tools
- Nodes connected by thin flow lines
- Include:
  - MongoDB
  - Express.js
  - React.js
  - Node.js
  - Charting libraries
  - Authentication
  - AI / analytics services
  - REST APIs
- Visually show data flow relationships, not just a logo wall
- Keep one node subtly glowing

### Slide 6: System Architecture
- Horizontal 5-node pipeline:
  - User → API → Processing → Analytics → DB
- Each node should be a rounded rectangle with icon + label
- Use arrows between nodes
- Add lower output branches for:
  - Dashboard views
  - AI insights
  - Alerts
  - Reports
- Add a small annotation showing data moves from devices to insights

### Slide 7: Features
- 6 feature cards in a 3×2 grid
- Each card must include:
  - Icon top-left
  - Title
  - One-line description
- Feature ideas:
  - Real-time energy dashboard
  - Water usage monitoring
  - Predictive AI insights
  - Smart alerts
  - Device analytics
  - Sustainability tracking
- Only the most important card gets cyan emphasis

### Slide 8: Dashboard UI Showcase
- This is the centerpiece slide
- Build a realistic mockup or wireframe of the EnerLuma dashboard
- Left 60%: dashboard frame with nav, KPI cards, and a bar chart
- Right 40%: 3 smaller stacked panel previews
- Add thin callout lines to key elements such as:
  - Live KPIs
  - Trend chart
  - Alerts panel
  - AI insights
- The mockup should look like a real product screenshot, but can be stylized
- Use subtle internal glow on the primary dashboard panel only

### Slide 9: Testing & Results
- Horizontal bar chart for test pass rates
- Below it, a tight row of 5 mini stat cards with:
  - Metric name
  - Value
  - PASS badge
- Suggested test metrics:
  - UI responsiveness
  - API connectivity
  - Data ingestion
  - Alert trigger accuracy
  - Build stability
- Keep chart thin and understated, with one amber highlight for the weakest area if needed

### Slide 10: Future Scope
- Vertical timeline or roadmap
- Include phases 2, 3, and 4
- Use a thin vertical line connecting the phases
- Each phase should have one icon and one-line description
- Suggested roadmap:
  - Phase 2: IoT device integration
  - Phase 3: ML-based predictive optimization
  - Phase 4: Mobile app and voice assistant support
- Keep the layout tall and elegant

### Slide 11: Conclusion
- Full-width bold statement headline
- 4 impact points below in a 2×2 card grid
- Minimal, confident, premium
- Suggested headline:
  - **EnerLuma turns utility data into decisions.**
- Impact points:
  - Clearer consumption visibility
  - Faster anomaly detection
  - Better energy and water savings
  - Scalable MERN architecture

### Slide 12: Team / Closing
- Final closing slide
- Include team names, mentor name, course, and university
- Add a simple thank-you line
- Visual style should be calm and polished, like a final investor outro
- Optional small footer note:
  - Lovely Professional University
  - CSE439 Capstone Project
  - 2024–25

## Designer Notes

- Use subtle motion only if the presentation tool supports it: fade, drift, or staggered reveal
- Keep all charts and diagrams realistic, not decorative
- Do not use cheesy icons, clip-art, or stock illustrations
- Do not overcrowd any slide
- Prefer 1 strong visual idea per slide
- Make the deck look expensive, credible, and human-made

## Optional Presentation Subtitle Line

If needed, use this line on the cover or closing slide:

**A smart home dashboard for energy efficiency, water conservation, and actionable AI insight.**
